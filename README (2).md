# フェリスの自己紹介ページ (Profile Web Page)

Web制作の学習（HTML / CSS）のために作成した、カード型レイアウトの自己紹介Webページです。ヘッダーのナビゲーションボタンをクリックすると、スムーズに対象の項目へスクロールする機能を備えています。

## 📁 構成ファイル

- `index.html` - ページの構造およびコンテンツ記述
- `style.css` - カードデザイン、ボタンデザイン、アニメーション等のスタイル定義
- `README.md` - プロジェクトの概要説明書

## ✨ 特徴・機能

1. **カード型コンポーネントデザイン (`.box`)**
   - 各コンテンツ（基本情報、好きなこと、ひとこと）を独立した箱（カード）で囲み、視認性を高めています。
2. **スムーススクロール機能**
   - ヘッダー内のナビゲーションボタン（`基本情報` `好きなこと` `ひとこと`）を押すと、ページ内の該当セクションへ滑らかに移動します。
3. **レスポンシブ考慮**
   - スマホやタブレットなどの小さな画面でも崩れにくいシンプルかつ柔軟なレイアウト設計です。

## 🚀 使い方・表示方法

1. リポジトリをローカルにダウンロードまたはクローンします。
2. `index.html` ファイルを任意のWebブラウザ（Chrome, Safari, Edgeなど）で開くだけで確認できます。

## 🛠️ 使用技術

- **HTML5**
- **CSS3** (`Flexbox`, `CSS Smooth Scroll`)
